## 概述

### 设计目的
`ocpu_execute` 是 OCPU RISC-V RV64I 处理器核心的执行单元，负责执行所有运算指令，包括：
- 基本算术逻辑运算（ALU）- 10个单发射单元
- 乘法和乘加运算（MUL/MAC）- 6个多发射单元
- 整数除法运算 - 2个除法单元
- 浮点运算（FPU）- 6个浮点单元
- 向量运算（VPU）- 8个向量单元
- CSR（控制和状态寄存器）访问
- 条件标志更新

### OCPU 3.0 关键特性
- **高并行架构**: 10 SX + 6 MX + 6 FPU + 8 VPU + 8 LSU
- **16发射支持**: 每周期最多16条指令执行
- **512-bit数据通路**: 向量单元1024位VLEN支持
- **3nm工艺优化**: 支持3GHz+频率
- **多级流水线**: 1-6级可变深度流水线
- **结果前递**: 大规模前递网络支持32个结果源

## 模块详细分析

### 1. 顶层模块: ocpu_execute

#### 功能
- 接收发射队列的16条指令
- 分发到44个执行单元
- 收集执行结果
- 处理异常和旁路

#### 3.0版本接口

```systemverilog
module ocpu_execute #(
    parameter XLEN          = 64,           // 64位架构
    parameter VLEN          = 1024,         // 1024位向量长度
    parameter ISSUE_WIDTH   = 16,           // 16发射宽度
    parameter NUM_SX        = 10,           // 10个单发射单元
    parameter NUM_MX        = 6,            // 6个多发射单元
    parameter NUM_FPU       = 6,            // 6个浮点单元
    parameter NUM_VEC       = 8,            // 8个向量单元
    parameter BUS_WIDTH     = 512           // 512-bit总线
)(
    // 时钟和复位
    input  wire                     clk,
    input  wire                     reset_n,
    
    // 输入: 16条指令
    input  wire [ISSUE_WIDTH-1:0]   valid_i,
    input  wire [ISSUE_WIDTH*64-1:0] inst_info_i,  // 64-bit每条
    input  wire [ISSUE_WIDTH*6-1:0]  eu_type_i,    // 执行单元类型
    input  wire [ISSUE_WIDTH*9-1:0]  src0_i,       // 源操作数0 (512物理寄存器)
    input  wire [ISSUE_WIDTH*9-1:0]  src1_i,       // 源操作数1
    input  wire [ISSUE_WIDTH*9-1:0]  dest_i,       // 目的寄存器
    
    // 操作数数据 (512-bit广播)
    input  wire [511:0]             op_data_i [0:1],  // 2个源操作数
    
    // 输出: 执行结果
    output wire [31:0]              result_valid_o,   // 32个结果有效位
    output wire [32*64-1:0]         result_data_o,    // 32个64-bit结果
    output wire [32*9-1:0]          result_dest_o,    // 32个目的寄存器号
    
    // 前递接口
    output wire [31:0]              bypass_valid_o,
    output wire [32*64-1:0]         bypass_data_o,
    
    // 控制信号
    input  wire                     flush_i,
    input  wire                     stall_i,
    output wire                     ready_o
);
```

### 2. 单发射执行单元 (SX) - 10个

#### 功能
- 执行基本整数ALU运算
- 1周期延迟
- 支持: ADD/SUB/AND/OR/XOR/SLT/SLTU/SLL/SRL/SRA

#### 结构
```
ocpu_sx_alu.sv (10个实例)
├── 操作数选择 (前递/寄存器)
├── ALU运算
│   ├── 加法器
│   ├── 逻辑运算
│   └── 移位器
├── 标志生成
└── 结果输出
```

#### 配置参数
```systemverilog
`define OCPU_NUM_SX       10
`define OCPU_SX_LATENCY   1
```

### 3. 多发射执行单元 (MX) - 6个

#### 功能
- 执行乘法/乘加运算
- 3周期延迟 (3nm优化)
- 支持: MUL/MULH/MULHU/MULHSU/MAC

#### 结构
```
ocpu_mx_mac.sv (6个实例)
├── Booth编码
├── 部分积生成
├── Wallace树压缩
├── 最终加法
└── 结果输出
```

#### 配置参数
```systemverilog
`define OCPU_NUM_MX       6
`define OCPU_MX_LATENCY   3
```

### 4. 浮点执行单元 (FPU) - 6个

#### 功能
- IEEE 754-2008浮点运算
- 4周期延迟
- 支持: FADD/FSUB/FMUL/FDIV/FMA/FCVT/FCMP

#### 结构
```
ocpu_fpu_top.sv (6个实例)
├── FPU控制
├── 加法单元
├── 乘法单元
├── 除法单元 (迭代)
├── FMA单元
└── 舍入逻辑
```

### 5. 向量执行单元 (VPU) - 8个

#### 功能
- 1024-bit SIMD向量运算
- 6周期延迟
- 支持: VADD/VMUL/VFMUL/VRED/VSLIDE

#### 结构
```
ocpu_vpu_top.sv (8个实例)
├── VPU控制
├── 8个向量lane (每lane 128-bit)
├── 向量ALU
├── 向量乘法
├── 归约树
└── 结果打包
```

## 流水线设计

### 执行流水线 (可变深度)

```
Cycle 1: 分发 (Dispatch)
┌─────────────────────────────────────────────────────────────────┐
│  从发射队列接收16条指令                                           │
│  根据EU类型分发到44个执行单元                                      │
│  读取源操作数 (寄存器/前递)                                        │
└─────────────────────────────────────────────────────────────────┘

Cycle 2: 执行 (Execute) - SX单元完成
┌─────────────────────────────────────────────────────────────────┐
│  SX0-9: 基本ALU运算完成 (1周期)                                  │
│  BR0-3: 分支计算完成                                             │
│  结果进入前递网络                                                │
└─────────────────────────────────────────────────────────────────┘

Cycle 3: 多周期执行 - MX单元
┌─────────────────────────────────────────────────────────────────┐
│  MX0-5: 部分积压缩                                               │
│  SX结果继续前递                                                  │
└─────────────────────────────────────────────────────────────────┘

Cycle 4: 多周期执行 - FPU/VPU
┌─────────────────────────────────────────────────────────────────┐
│  FPU0-5: 浮点运算进行中                                          │
│  VPU0-7: 向量运算进行中                                          │
│  MX0-5: 最终加法，结果输出 (3周期完成)                            │
└─────────────────────────────────────────────────────────────────┘

Cycle 5-6: 向量深度执行
┌─────────────────────────────────────────────────────────────────┐
│  VPU0-7: 向量归约/打包                                           │
│  FPU0-5: 舍入处理，结果输出 (4周期完成)                           │
└─────────────────────────────────────────────────────────────────┘

Cycle 7: 向量完成
┌─────────────────────────────────────────────────────────────────┐
│  VPU0-7: 1024-bit结果输出 (6周期完成)                            │
└─────────────────────────────────────────────────────────────────┘
```

## 接口定义

### 与发射队列接口

```systemverilog
// 输入: 16条指令
input  wire [15:0]              issue_valid_i,      // 16条指令有效
input  wire [15:0][63:0]        issue_pc_i,         // PC (64-bit x 16)
input  wire [15:0][31:0]        issue_inst_i,       // 指令编码 (32-bit x 16)

input  wire [15:0][8:0]         issue_src1_i,       // 源1物理寄存器号
```
