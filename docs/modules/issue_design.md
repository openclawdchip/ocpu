# OCPU Issue 模块设计文档 - 版本3.0

## 文档信息
- **模块名称**: ocpu_issue (指令发射单元)
- **版本**: OCPU-RV64I-r3p0
- **工艺节点**: 3nm
- **总线宽度**: 512-bit
- **更新日期**: 2026-02-13

---

## 概述

`ocpu_issue` 是 OCPU 处理器的指令发射单元，负责从发射队列中选择就绪指令，分发到执行单元，并处理唤醒和前递逻辑。

### OCPU 3.0 特性

| 特性 | 配置 |
|------|------|
| **发射宽度** | 16条指令/周期 |
| **整数发射队列 (SXQ)** | 40深度 |
| **访存发射队列 (LSQ)** | 48深度 |
| **乘加发射队列 (MXQ)** | 32深度 |
| **分支发射队列 (BXQ)** | 32深度 |
| **向量发射队列 (VXQ)** | 48深度 |
| **总线宽度** | 512-bit |
| **唤醒端口** | 32个结果源 |

## 核心模块详细分析

### 1. 发射队列 (Issue Queues)

#### 整数发射队列 (SXQ) - 40深度

```systemverilog
module ocpu_is_sxq #(
    parameter DEPTH = 40,
    parameter ISSUE_WIDTH = 10,         // 10 SX单元
    parameter WAKEUP_PORTS = 32         // 32个唤醒源
)(
    input  wire                     clk,
    input  wire                     reset_n,
    
    // 分发输入
    input  wire [15:0]              dispatch_valid_i,  // 最多16条分发
    input  wire [15:0][8:0]         dispatch_src0_i,   // 源0 (9-bit phys reg)
    input  wire [15:0][8:0]         dispatch_src1_i,   // 源1
    input  wire [15:0][8:0]         dispatch_dest_i,   // 目的
    
    // 唤醒输入 (32个执行单元结果)
    input  wire [31:0]              wakeup_valid_i,
    input  wire [31:0][8:0]         wakeup_dest_i,
    
    // 发射输出 (10条)
    output wire [9:0]               issue_valid_o,
    output wire [9:0][8:0]          issue_src0_o,
    output wire [9:0][8:0]          issue_src1_o,
    output wire [9:0][8:0]          issue_dest_o
);
```

#### 访存发射队列 (LSQ) - 48深度, 8发射

### 2. 记分板 (Scoreboard)

```systemverilog
module ocpu_is_scoreboard #(
    parameter NUM_PREG = 512,           // 512物理寄存器
    parameter READ_PORTS = 32,          // 32读端口 (16指令 x 2源)
    parameter WRITE_PORTS = 32          // 32写端口 (32个执行单元)
)(
    input  wire                     clk,
    input  wire                     reset_n,
    
    // 读端口: 查询源操作数是否就绪
    input  wire [31:0][8:0]         read_addr_i,       // 32个9-bit物理寄存器号
    output wire [31:0]              read_ready_o,      // 32个就绪位
    
    // 写端口: 标记目的寄存器为未就绪 (分发时)
    input  wire [31:0]              write_set_i,       // 设置未就绪
    input  wire [31:0][8:0]         write_addr_i,
    
    // 清除端口: 执行完成标记就绪
    input  wire [31:0]              clear_i,           // 32个执行单元完成
    input  wire [31:0][8:0]         clear_addr_i
);
```

```

│   32个执行单元结果源                                                          │
│       │                                                                      │
```

### 4. 调度器 (Scheduler)

```systemverilog
module ocpu_is_scheduler #(
    parameter NUM_QUEUES = 6,           // SXQ/LSQ/MXQ/BXQ/VXQ/其他
    parameter TOTAL_ENTRIES = 214,      // 总发射队列项
    parameter ISSUE_WIDTH = 42          // 总发射宽度 (10+8+6+4+8+6)
)(
    input  wire                     clk,
    input  wire                     reset_n,
    
    // 就绪输入 (来自所有队列)
    input  wire [213:0]             ready_i,           // 214个就绪位
    input  wire [213:0][63:0]       age_i,             // 214个年龄 (ROB索引)
    
    // 选择输出
    output wire [41:0]              select_o,          // 42个选择信号
    output wire [41:0][7:0]         queue_id_o         // 每个选择的队列ID
);
```
