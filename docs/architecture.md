# OCPU 64位架构概述 - 版本3.0

## 1. 简介

OCPU（Open CPU）是一个开源的**纯64位**超标量处理器核心设计，基于 RISC-V RV64I/M/F/D/V 指令集架构。当前版本采用**3nm工艺**和**512-bit总线**的高性能配置。

> ⚠️ **重要**: 本设计仅支持64位架构，所有寄存器、地址和数据通路均为64位宽。

## 4. OCPU 3.0 架构特性

### 4.1 工艺与总线

| 特性 | 规格 | 说明 |
|------|------|------|
| **工艺节点** | 3nm | 先进半导体工艺 |
| **总线宽度** | 512-bit | 4倍带宽提升 |
| **时钟频率** | 3GHz+ | 最高支持4GHz |
| **工作电压** | 0.5V-0.85V | 低功耗设计 |
| **晶体管密度** | 200-250 MTr/mm² | 3nm工艺特性 |

### 4.2 核心配置

| 特性 | 规格 | 说明 |
|------|------|------|
| 架构 | RV64I/M/F/D/V | 完整64位RISC-V |
| **发射宽度** | **16条指令/周期** | 超标量设计 |
| **ROB深度** | **256项** | 乱序执行 |
| **物理寄存器** | **512个** | 整数/浮点寄存器 |
| 寄存器位宽 | 64位 (XLEN=64) | 整数/浮点寄存器 |
| **向量寄存器** | **1024位 (VLEN=1024)** | 256个物理向量寄存器 |
| 虚拟地址 | 64位 | Sv39/Sv48支持 |
| **物理地址** | **52位** | 4PB物理内存 |
| 页大小 | 4KB/2MB/1GB | 标准RISC-V页 |

### 4.3 执行单元配置

| 单元类型 | 数量 | 说明 |
|----------|------|------|
| 整数ALU (SX) | 10 | 单发射执行单元 |
| MAC (MX) | 6 | 乘加单元 |
| FPU | 6 | IEEE 754-2008浮点 |
| VPU | 8 | 1024位向量单元 |
| LSU | 8 | 4 Load + 4 Store |
| 分支单元 | 4 | 分支预测执行 |

### 4.4 缓存配置

| 缓存 | 大小 | 路数 | 接口宽度 |
|------|------|------|----------|
| **L1-I Cache** | **256KB** | 8-way | 512-bit |
| **L1-D Cache** | **64KB** | 8-way | 512-bit |
| **L2 Cache** | **4MB** | 16-way | 512-bit |
| 缓存行 | 64 bytes | - | - |

## 6. 关键特性说明

### 6.1 3nm工艺优势

- **功耗降低**: 相同性能下25-30%功耗降低
- **性能提升**: 相同功耗下10-15%性能提升
- **电压范围**: 支持0.5V-0.85V宽电压运行
- **频率支持**: 最高可达4GHz

### 6.2 512-bit总线优势

- **带宽提升**: 4倍于128-bit总线
- **数据传输**: 每周期传输64字节
- **发射匹配**: 完美匹配16指令发射宽度
- **缓存接口**: L1/L2统一512-bit接口

### 6.3 向量处理

- **VLEN=1024**: 1024位向量长度
- **256物理寄存器**: 充足的向量寄存器资源
- **8向量单元**: 高并行度向量计算
- **3 TFLOPS**: @3GHz向量性能
