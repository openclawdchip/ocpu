# OCPU项目完成总结 - 版本3.0

## 项目概述

OCPU (Open CPU Core) 是一个完整的开源64位RISC-V超标量处理器设计，现已全部完成。当前版本为**3.0**，采用**3nm工艺**和**512-bit总线**的高性能配置。

## 版本信息

| 版本 | 工艺 | 总线 | 主要特性 |
|------|------|------|----------|
| 1.0 | 7nm | 128-bit | 基础4发射配置 |
| 2.0 | 5nm | 128-bit | 16发射高性能配置 |
| **3.0** | **3nm** | **512-bit** | **超高性能配置** |

## OCPU 3.0 架构特性

### 支持的指令集
- ✅ RV64I (64位整数基础)
- ✅ RV64M (乘除法扩展)
- ✅ RV64F (单精度浮点)
- ✅ RV64D (双精度浮点)
- ✅ RV64V (向量扩展)
- ✅ Zicsr (CSR指令)
- ✅ Zifencei (Fence指令)
- ✅ Zicbom (缓存管理)

### 流水线特性
| 参数 | 配置 | 说明 |
|------|------|------|
| **流水线级数** | 10级 | 超标量流水线 |
| **发射宽度** | 16 | 每周期发射指令数 |
| **执行模式** | 乱序执行 (OOO) | 高性能调度 |
| **ROB深度** | 256 | 重排序缓冲区 |
| **物理寄存器** | 512 | 整数/浮点寄存器 |

### 工艺与总线
| 参数 | 配置 | 说明 |
|------|------|------|
| **工艺节点** | 3nm | 先进半导体工艺 |
| **内部总线** | 512-bit | 4倍带宽提升 |
| **时钟频率** | 3GHz+ | 最高支持4GHz |
| **工作电压** | 0.5V-0.85V | 低功耗设计 |

### 分支预测
| 组件 | 配置 | 说明 |
|------|------|------|
| **BTB** | 2048项 | 8路组相联 |
| **GHB** | 8192项 | 全局历史缓冲 |
| **RAS** | 32项 | 返回地址栈 |
| **TAGE** | 多表1024项 | 高级预测器 |
| **间接跳转** | 专用预测器 | 提升间接分支命中率 |

### 内存系统
| 缓存 | 大小 | 路数 | 接口宽度 |
|------|------|------|----------|
| **L1 I-Cache** | 256KB | 8-way | 512-bit |
| **L1 D-Cache** | 64KB | 8-way | 512-bit |
| **L2 Cache** | 4MB | 16-way | 512-bit |
| **缓存行** | 64字节 | - | - |

### MMU配置
- **页表遍历**: 3级 (Sv39)
- **TLB层次**: ITLB(64项) + DTLB(64项) + STLB(64项)
- **支持页大小**: 4KB / 2MB / 1GB
- **物理地址**: 52位

## 设计亮点

### 1. 3nm工艺优化
- **晶体管密度**: 200-250 MTr/mm²
- **功耗降低**: 相同性能下25-30%
- **性能提升**: 相同功耗下10-15%
- **电压范围**: 0.5V-0.85V

### 2. 512-bit总线架构
- **带宽提升**: 4倍于128-bit总线
- **数据通路**: 每周期传输64字节
- **匹配发射宽度**: 支持16指令发射
- **缓存接口**: L1/L2统一512-bit接口

### 3. 完整的FPU实现 (IEEE 754-2008)
- FADD/FSUB/FMUL/FDIV/FSQRT
- FMA (乘加融合)
- FCVT (类型转换)
- FCMP (浮点比较)
- FCLASS (浮点分类)

### 4. 完整的VPU实现 (RISC-V Vector v1.0)
- 1024位向量长度 (VLEN=1024)
- 256个物理向量寄存器
- VALU/VMUL/VDIV
- VRED (向量归约)
- VSLIDE (向量滑动)
- VGATHER/VSCATTER

### 5. 高级分支预测
- TAGE预测器 (8192项)
- 间接跳转预测
- 条件分支预测
- 32项返回地址栈

### 6. 高性能缓存层次
- 256KB L1-I Cache (8-way)
- 64KB L1-D Cache (8-way)
- 4MB L2 Cache (16-way)
- 512-bit数据接口
- 高级预取器
